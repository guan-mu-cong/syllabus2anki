# 数据合规矩阵（compliance.md）

本仓库定位：**工具与方法论开源，词典内容不随仓分发**。
下面逐类说清楚什么在仓库里、什么不在、为什么。

## 仓库内（可自由分发，MIT）

| 内容 | 说明 |
|------|------|
| `pipeline/**` 全部代码 | 自研 + vendor 自作者私有生产管线（作者自己的代码，MIT 授权） |
| `assets/templates/v5_*` | 卡面 HTML/CSS 模板，自研设计 |
| `examples/mini20/**` | **完全合成**的演示数据：释义/例句/短语全部手写虚构，仅模仿缓存 JSON 的 schema，不含任何真实词典内容 |
| `docs/**`、README、LICENSE | 方法论文档 |

## 仓库外（用户自行获取，不得随仓分发）

| 数据 | 来源 | 为什么不能进仓库 |
|------|------|------------------|
| 词典释义缓存（`yd_cache/`） | 有道公开词典接口（02 阶段抓取） | 抓取内容版权归词典方；仅供**个人学习**本地缓存。再分发 = 侵权。接口本身为非官方公开端点，请控制频率、遵守对方服务条款与所在地法律 |
| 柯林斯星级/释义块 | 同上（jsonapi collins 字段） | 柯林斯为 HarperCollins 版权内容，同上 |
| 发音音频（`audio32/`） | 词典 TTS 端点（03 阶段） | 同上；且体积大 |
| 真题例句与译文 | 历年真题（用户自备语料，04/05 消费） | 试题内容版权归考试机构/出版方 |
| COCA 义项分布索引（`hbs_index.json`） | 商业词汇书衍生索引（作者私建） | 底层数据有版权，索引不外发；缺省自动降级为 wordfreq 排序 |
| 词根助记索引（`engra_index.json`) | 商业 App 衍生 | 同上 |
| 官方大纲 PDF 本体 | 考试院出版物 | 版权文件不转载；01 阶段读你本地的副本 |
| `cards*.json`、`.apkg` 成品 | 上述数据衍生物 | 衍生内容同样不可分发 |

## 大纲词表本身

官方大纲的**单词清单**（哪些词、哪些带★、在第几页）属于事实性数据，
本仓库的 01 阶段直接从你本地的官方 PDF 提取，不随仓附带任何 PDF 内容或提取结果。

## 第三方开源依赖

| 依赖 | 许可 | 用途 |
|------|------|------|
| PyMuPDF | AGPL-3.0（个人使用无碍；商用注意） | PDF 文本层提取 |
| wordfreq | MIT（其数据源各自署名见包内） | 通用词频排序 |
| PyYAML / requests | MIT / Apache-2.0 | 配置与 HTTP |
| ffmpeg | LGPL/GPL（独立二进制，需自行安装） | 音频转码 |
| Anki / AnkiConnect | AGPL / GPL | 目标平台 |

## 使用立场

1. 本项目为**个人学习工具**。用它抓取的词典内容与音频仅供你本人背词使用。
2. 想分享牌组？分享**代码与流程**（本仓库），让每个人跑自己的 02/03/04——
   而不是分发抓取产物或成品 `.apkg`。
3. `config.local.yaml` 含本机路径与凭据指针，已被 gitignore；提交前跑一遍
   README 里的脱敏扫描。
