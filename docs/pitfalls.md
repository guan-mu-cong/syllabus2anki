# 坑清单 · 官方大纲 PDF 词表提取

> 从真实铸卡管线蒸馏（CET 2016 大纲跑通：7805 词条 / ★1263 / 变体 208）。
> 这里每一条都是实际踩过并修复的坑，不是假想清单。对应模块：`pipeline/01_extract_wordlist.py`。

## 一、PDF 文本层的七类破坏

### 1. 全角"Ｇ"(U+FF27) = 牛津式重复前缀记号（不是错字！）
- `center/Ｇtre` → **centre**（第二拼写复用第一拼写的前 `len(first)-len(rest)` 个字母）
- `advisor/Ｇer` → adviser；`colonize/Ｇise` → colonise
- 出现在词中间（无斜杠）时是**连字符**：`airＧconditioning` → air-conditioning
- **必须在 NFKC 归一化之前**把 Ｇ 换成占位符（如 `\x01`）：NFKC 会把它变成普通 `G`，信息永久丢失
- 想当然换成 `e` 会产出 `center/etre`、`besteseller` 这类垃圾
- 占位符要加进所有行过滤正则的字符类，否则整行被误杀

### 2. 折行断裂
实测形态：`marvel(` + `l)ous`、`mo(u)` + `ld`、`fulfil(` + `l)`。
- 信号 A：行内括号不配平 → 与下一行拼接
- 信号 B：括号配平但行以 `)` 结尾且下一行是 1-4 个小写字母（`mo(u)` 这种配平断裂只能靠它）
- **拼接结果必须能在词典缓存里查到**才接受，否则 `ax(e)` + `axis` 会拼成 `axaxis`
- 拼接过度同样是坑：合并规则收紧后 `mo(u)ld` 可能反而不合并，要按"合并后是真实词"判定而非形态猜测

### 3. 空格被吞
`accordingto`、`owingto`、`babyboom`、`coupd'état`。
- 不能靠猜分词：对每个插空格位置查词典缓存，**命中唯一**才接受
- 短语在缓存中的文件名保留原始空格（与单词的 sanitize 规则不同，见 §二）

### 4. 括号变体括注
`mom(my)`、`program(me)`、`ag(e)ing`、`coup(d'état)` → 一行只出一张卡：主形做词头，其余进 variants。
- **变体拼接二次坑**：`coup(d'état)` 去括号展开是 `coupd'état`（丢空格）——variants 生成后必须再跑一遍空格/撇号还原

### 5. 斜杠双拼写
`center/Ｇtre`、`analyze/-yse`：斜杠两侧解析后，第二形走 Ｇ 还原；两形同为词头时只留第一个，另一个进 variants。

### 6. 噪声行
- 全角义项序号行（`１` `２`）：直接丢
- 样卷区标题（Part/Section/Directions/全国大学…）：BAD 正则拦截
- 选项字母（`A)` `B.`）与题号（`Questions…`）：单独正则拦截
- 全角数字要过 NFKC 变半角后才好判

### 7. 单词条末页（最阴险——生产环境真实丢过 1 个★词）
CET2016 词表最后一页（p148）**只有一个词条 `★zoom`**，后面跟着印刷总数 5418/2551。
- "当页条目 <3 就跳过"的稀疏页过滤把它**静默吃掉**，生产牌组因此少了一张★卡（重构回归时才抓到）
- 修复：人工核实过的 `page_end` 末页用 ≥1 条的阈值；内部页保留稀疏过滤（防目录/空白页混入）
- 教训：**任何"每页至少 N 条"的启发式，都要问一句"最后一页呢？"**

## 二、词典探针与两轮 bootstrap

所有修复判定（"拼出来的是不是真词"）都需要一个词典 oracle：
- 实现 = 每词一个 JSON 的缓存目录（由 `02_fetch_dict.py` 产出）
- 文件名约定：**单词** sanitize（`[^A-Za-z-' ]` → `_`）；**短语**保留原名（含空格/撇号）
- 文件 ≤200 字节视为 miss（抓取失败的错误存根）
- **鸡生蛋问题**：第一轮提取时还没有缓存 → 修复保守跳过 → 拿粗词表去抓词典 → 第二轮重跑提取获得完整修复（two-pass bootstrap）。探针缺位时模块会打印 DISABLED 警告而不是静默降级。

## 三、head_fixups：通用规则判不了的个案

`ag(e)ing` 案例：PDF 把它折行拆成 `ag(e)` + `ing` 两行，`ag` 成为伪词条——而词典**真的收录 ag**（银的化学符号），探针无法拒绝；`age` 和 `ing`（惯性导航缩写）又都是真实独立词头。
- 处理：config 里 `head_fixups: {ag: drop}`，**必须附注释**说明破坏形态与人工核实方式
- 原则：个案用带文档的 fixup 表，不硬造通用规则（误伤面不可控）；同生产管线里 `regret` 核心义硬编码的先例

## 四、与生产基线（official_words_v4.json）的已知差异

生产基线是"脚本输出 + 人工补丁"的产物（coup d'état 手改、ag 手删、ing 手工挪到表尾）。本模块输出是**可复现**的，对基线的差异全部可解释：
- **+zoom**（基线缺陷，见 §一.7）
- `ing` 的页码溯源 [22]（折行残片行）vs 基线 [23]（人工编辑值）；条目内容一致
- 顺序：剔除 ing/zoom 后与基线 100% 一致
- 下游卡片顺序由排序键（价值档位+词频）决定，与词条顺序无关 → 差异零影响

## 五、自检清单（config `self_check_words`）

| 探针词 | 验证什么 | 期望 |
|---|---|---|
| centre / adviser / colonise / fibre / practice / amongst | 斜杠双拼写+Ｇ还原 | 作为 center/advisor/colonize/fiber/practise/among 的**变体**找到 |
| marvelous / mold | 折行合并 | 词头找到，变体 marvellous/mould 在列 |
| axis / logistics | 拼接污染防护（ax(e)+axis 没被拼坏） | 词头独立存在 |
| o'clock / cliché | 撇号变体字符 + 变音字母保留 | 词头找到 |
| according to / owing to / coup | 空格还原（coup 经变体二次还原） | 词头找到，coup 变体 = coup d'état |
| zoom | 单词条末页 | 词头找到（★） |

注意：**aging 故意不在清单里**——`ag(e)ing` 破坏的最终正确解是 age、ing 两个独立词头，词表本来就不收 aging。

收尾硬校验：任何词头仍含 `( )` 或占位符 = 残留异常，必须为 0，模块以非零退出码报错。

## 下游阶段坑（02-07，M3 回归实录）

1. **音频文件名历史变体**：早期脚本保留大小写（`yd_Catholic_us.mp3`），p2 的 `fname()` 全小写；重音词（cliché/résumé）与含空格词（owing to）历史上产生过多种命名副本并存于同一目录。重建 map 自洽（每个值都指向存在的文件），但与旧 map 逐字节比对必炸——回归前先对齐命名系。
2. **Anki 精确搜索**：`字段:=值` 语法在部分版本经 AnkiConnect 返回 0 条。实卡对撞用 `字段:值`（子串）召回 + 程序侧全等过滤才稳。
3. **addNotes 整批炸**：一批里只要有一张重复卡，整批失败且 error 含 "duplicate"——必须实现逐条重投兜底（06 内置），否则断点续跑会反复卡在同一批。
4. **译文缓存 key**：= 清洗后英文句（剥前导编号、弯引号原样），必须与建卡端 `_zh_for` 完全一致，否则缓存永不命中、LLM 白烧。
5. **烘焙幂等但输入有系**：p6 已有同词加粗则跳过（重跑安全）；生产 `cards.json` 存在两个历史系（work=音频引用保留大小写 / repo=小写规范化），字节级回归必须喂当年那份输入。
6. **notesInfo 响应体量**：全牌组扫描时 200 张一批分块处理、即扫即弃聚合，别把几千张卡的 HTML 全 hold 在内存里。
